# HTML Learning Journey 🌐

This folder contains my work while learning **HTML from the basics**.

I built these pages myself while learning how HTML works, practicing different tags, fixing errors, and understanding how to structure a complete website.

## 📚 What I Learned

- HTML document structure
- Headings and paragraphs
- Links and navigation
- Images
- Lists
- Tables
- Forms
- Input types
- Labels
- Select and textarea
- Semantic HTML
- `header`, `nav`, `main`, `section`, `article`
- `figure` and `figcaption`
- `iframe`
- Multi-page website structure

## 🛠️ Projects

### 🍽️ Restaurant Website

A multi-page restaurant website created using HTML.

Pages include:

- Home
- Menu
- About
- Gallery
- Reservation
- Contact

The project helped me practice connecting multiple HTML pages, creating forms, displaying images, embedding maps, and organizing content using semantic HTML.

## 🧠 Learning Approach

I am learning HTML by **writing the code myself**, making mistakes, finding the problems, and fixing them.

Instead of only copying code, I try to understand:

- Why a particular HTML tag is used
- How different elements work together
- How pages are connected
- How to structure a website properly
- How to debug my own mistakes
